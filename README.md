# Brooklyn Nail Booking

Create a nail salon booking web app called NailingUp based in Brooklyn, NY. The app is for a solo owner named Maya.

Set up the project with the following:

• React with React Router for multi-page navigation
• Tailwind CSS for styling
• Brand colors: primary deep mauve #6B3F5E, background blush #F5E6EE, accent gold #C9A84C, text dark #2D2D2D
• Fonts: Playfair Display for headings, Inter for body text (import both from Google Fonts)
• Routes: / (landing), /book (booking flow), /confirmation (confirmation), /dashboard (owner dashboard)
• A shared layout with a sticky top nav containing the logo text "NailingUp" on the left and a "Book Now" button on the right that links to /book

For now, each route can show a simple placeholder page with just the page name. We will build each page in follow-up prompts.

Do not add any authentication. Do not add a backend. All state will be managed in-app with React state or context.
